# Quentin Ikuta conservation stewardship website

This is a fresh static website package built with the uploaded images included in assets/images.

How to use with GitHub Desktop:

1. Unzip this package.
2. Open your website repository in GitHub Desktop.
3. Copy all files and folders from this package into the repository root.
4. Let the included assets/images folder replace the broken image folder.
5. Review the changes in GitHub Desktop.
6. Commit with: Fresh conservation stewardship site with working image assets
7. Push to GitHub.

The site is intentionally positioned for broad conservation, public service, Tribal engagement, GIS, natural resources, agriculture, transportation landscapes, and cross-sector stewardship roles.
