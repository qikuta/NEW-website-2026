# Quentin Ikuta Conservation Stewardship Website Update

This package is a full replacement for the main static website files in the GitHub Pages repository.

## What changed

The site now positions Quentin Ikuta as a broad conservation and stewardship professional rather than a forestry, carbon, or agriculture specialist. The strongest transferable frame is conservation stewardship across landscapes, communities, agencies, and public systems.

## Sector fit

The copy is written to work across nonprofits, state agencies, Tribal natural resource partners, conservation organizations, transportation programs, agriculture programs, economic development teams, cities, counties, and watershed organizations.

## How to update with GitHub Desktop

1. Download and unzip this package.
2. Open your website repository in GitHub Desktop.
3. Copy these files into the repository root.
4. Keep the existing assets/images folder.
5. In GitHub Desktop, review changed files.
6. Commit with a message such as: Reposition website around conservation stewardship and public service.
7. Push to GitHub.

## Visual direction

The design keeps the dark, field-based portfolio style and uses existing images throughout the site. The metaphor of a full connected system is carried through the structure and language rather than stated directly.
